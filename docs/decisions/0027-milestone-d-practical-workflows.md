# ADR 0027: CSV 중심 실무 작업을 마일스톤 D로 추가

## 상태

Accepted — 2026-10-24 (요구사항 계획 승인, 기능 구현 전)

## 배경과 결정

사용자가 CSV 기반 데이터 추가 등 실무에서 활용할 목표를 요청했다. 제품 기준
명세에 마일스톤 D를 추가하고, 좌표 CSV/TSV 입력 → 업무대장 속성 조인 → 필드 및
면적·길이 계산 → 검수 → 선택/필터 납품을 필수 범위로 정한다. 반복 작업 설정
재사용은 후속으로 둔다. 구체적 수용 기준은
[마일스톤 D 계획](../implementation/milestone-d-practical-workflows.md)에 둔다.

CSV는 좌표계·축 순서·인코딩·키 형식을 자체적으로 보장하지 않으므로 미리보기에서
사용자가 확정하고 샘플로 검증한다. 조인은 대장 쪽 키 중복을 차단하고 원본을
보존하는 결과 레이어 방식으로 시작한다. 표 입출력은 드라이버, 처리와 취소는
공용 명령 API, 미리보기와 오류 표시는 GUI에 배치한다.

## 영향과 제한

이 결정은 계획 문서만 추가하며 새 네이티브 의존성을 도입하지 않는다. 향후 의존성
도입 시 OS별 배포·라이선스 영향을 별도로 기록한다. Excel 직접 연결과 외부 주소
지오코딩은 포함하지 않으며, 기존 C와 OS별 배포 검증의 미완료 항목은 유지한다.
