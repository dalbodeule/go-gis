# ADR 0031: CSV 경계 식별자와 Lua 분리

상태: Accepted — 2026-10-24

측량 CSV는 시작점을 다시 측정하거나 점을 경계 순서로 기록한다고 가정하지 않는다.
사용자가 경계 계산을 선택하면 명시된 X/Y와 CRS에서 점들의 **볼록 외곽선**을
계산한다. 경계 그룹 필드를 지정하면 값마다 외곽선을 만들고, 비우면 전체 점으로
한 경계를 만든다. 서로 다른 세 점이 없거나 모두 일직선이면 실패한다. 결과 점과
경계 면에 DBF 호환 필드 `shape_id`를 `B000001`부터 부여한다. 볼록 외곽선은
오목한 실제 필지 경계를 복원하지 않으므로 사용자가 지도에서 결과를 확인해야 한다.
좌표 계산은 입력 CRS의 평면 좌표값을 사용하며 자동 CRS 변환은 하지 않는다.

같은 헤더와 필드 형식을 가진 CSV/TSV 파일을 입력 순서대로 하나의 점 레이어로
합친다. GUI의 10만 행·16 MiB 제한은 모든 파일의 합계에 적용한다. 원본 첫 파일의
행 기반 피처 ID를 보존하고 다음 파일 ID에 오프셋을 더해 중복을 피한다. 경계 계산
결과는 점 레이어와 면 레이어로 함께 추가하며 CLI에서는 GeoPackage 두 레이어로 쓴다.

SHP 면 레이어를 추가한 뒤 생성된 경계 레이어를 선택하면 GEOS 교차 연산으로
면을 잘라 `shape_id`별 새 레이어를 만든다. 경계에 닿기만 한 선·점 결과는 버린다.
GUI에서는 범위가 겹치는 최대 20만 후보 쌍의 교차 비교를 허용해 장시간 무응답을 막는다. CLI에는
이 대화형 한도를 적용하지 않는다. SHP 드라이버가 만든 `FID` 속성은 GeoPackage의
예약 필드와 충돌하므로 결과에서 `source_fid`로 보존한다.

Lua 필터는 피처마다 불리언을, Lua 레이어 분리는 문자열·숫자 식별자를 반환한다.
`nil` 또는 빈 문자열은 분리 결과에서 제외한다. 기존 제한된 Lua 평가기를 재사용하고
최대 64개 결과 레이어를 허용한다. GUI의 취소는 결과 레이어를 추가하기 전에 확인한다.
