# ADR 0028: 레이어 도형 잠금과 CSV 폴리곤·SHP 업무 흐름

상태: Accepted — 2026-10-24 (설계 결정, 신규 기능 구현 전)

사용자 요청에 따라 마일스톤 D에 레이어별 도형 편집 잠금, 빈 레이어 생성,
CSV/TSV 점 목록의 선택·순서 기반 폴리곤 생성, 자동 레이블 속성과 SHP 납품을
추가한다. 상세 정책과 수용 기준은
[보완 검토 문서](../implementation/milestone-d-editing-csv-shapefile.md)에 기록한다.

`Editable`은 쓰기 능력으로 유지하고 도형 잠금은 별도 정책으로 둔다. 기본 Lock,
확인된 쓰기 가능 빈 레이어 Unlock을 적용하며 GUI 이외의 공용 명령에서도 강제한다.
점 선택 집합만으로 경계를 추측하지 않고 정점 순서를 확정한 뒤 유효한 Polygon을
새 레이어로 만든다. 레이블 문자열은 일반 속성으로 보존하고 표시 스타일과 분리한다.

SHP writer와 CLI 기반은 이미 존재한다. 신규 포맷 드라이버를 중복 구현하지 않고
GUI 내보내기, 필드/인코딩 제약 사전 검증, 빈 형상 스키마와 파일 묶음 저장을 보강한다.
최초 출력은 새 대상만 허용해 기존 SHP 묶음의 불완전 덮어쓰기를 방지한다.
이 결정은 문서 변경이며 네이티브 의존성을 추가하지 않는다.
