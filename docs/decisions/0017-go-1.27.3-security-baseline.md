# ADR 0017: Go 1.27.3 보안 기준

## 상태

Accepted — 2026-10-23

## 결정

저장소의 Go 기준 버전은 Go 1.27.3으로 고정한다. `go.mod`의 `toolchain` 지시자로
로컬 및 CI가 동일한 패치 버전을 사용하도록 하고, 모듈 업데이트 후
`go test ./...`, `go vet ./...`, `govulncheck ./...`를 검증 게이트로 사용한다.

Go 1.27.3은 Go 공식 릴리스 기록상 `crypto/x509` 보안 수정이 포함된 패치 릴리스이며,
현재 모듈 그래프에 대해 `govulncheck`가 취약점을 보고하지 않는 것을 확인했다.

## 적용 범위

- `github.com/mappu/miqt`를 v0.15.0으로 갱신했다.
- `golang.org/x/sys`를 v0.49.0, `golang.org/x/text`를 v0.43.0,
  `golang.org/x/sync`를 v0.24.0으로 갱신했다.
- 네이티브 GIS 의존성의 버전 정책은 이 결정에 포함하지 않으며 기존 ADR을 따른다.
