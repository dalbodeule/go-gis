# ADR 0029: 마일스톤 D 공용 업무 명령 경계

상태: Accepted — 2026-10-24

마일스톤 D의 CSV/TSV 파싱, 좌표 검증, 선택 점의 순서 기반 폴리곤 생성,
레이블 필드 생성, 키 조인, 데이터 검수, 평면 측정은 `internal/commands`에
둔다. GUI는 미리보기와 결과 표시만 담당하고 CLI도 같은 함수와 결과 모델을
사용한다. CSV 속성은 첫 버전에서 문자열로 보존해 선행 0을 잃지 않게 한다.

도형 잠금은 `Editable`(소스가 쓸 수 있는가)와 분리한 `GeometryLocked` 정책으로
두며, Add/Delete/SetGeometry 명령에서 검사한다. 속성 편집은 도형 잠금과
분리한다. CRS나 단위는 값의 모양으로 추측하지 않고 호출자가 지정한다.

이번 변경은 네이티브 의존성을 추가하지 않았으며, CLI와 기본 SHP/GeoPackage
납품을 연결했다. 후속 GUI 흐름과 입력 제한은 ADR 0030에 기록한다.
