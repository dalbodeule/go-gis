# ADR 0022: QML 상태 메시지 prefix 순서 캐시

- 상태: 적용
- 기준일: 2026-10-24
- 범위: `cmd/gis-desktop/qml/Main.qml`의 상태 메시지 번역

## 결정

상태 메시지 번역 함수가 언어별 번역 사전과 접두사 목록을 매 호출마다 새로
생성·정렬하지 않도록 QML property에 언어별로 캐시한다.

## 이유

대형 레이어 로딩 중에는 상태 메시지가 짧은 주기로 갱신된다. 번역 사전과 접두사
목록은 언어가 바뀌지 않는 동안 불변이므로 호출마다 객체를 만들거나 정렬할
필요가 없다. 캐시는 영어·한국어·일본어별로 분리하고, 실제 번역 결과와 prefix
우선순위는 유지한다.

## 검증

- QML 소스 정적 검사 및 기존 QML 테스트를 실행한다.
- Go 일반/native/race 테스트와 native 데스크톱 빌드를 실행한다.
