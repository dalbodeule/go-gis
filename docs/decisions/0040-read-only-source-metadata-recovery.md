# 읽기 전용 레이어의 원본 메타데이터 복구

## 결정

화면 단위로 읽는 레이어에 원본 CRS나 유효한 범위가 없으면 전체 도형을 읽는
방식으로 전환하지 않는다. 해당 레이어는 원본 경로와 오류 사유를 유지한 채
사용할 수 없는 레이어로 표시하고, 다른 레이어의 화면 단위 렌더링은 계속한다.
사용 가능한 레이어가 하나도 없어도 빈 지도를 열어 레이어 속성에서 원본 CRS를
입력하거나 파일 경로를 고칠 수 있게 한다. 범위가 없으면 데이터셋의 범위
메타데이터를 복구해야 한다.

명시적으로 다시 불러오는 대상 레이어는 실패를 성공으로 처리하지 않는다.
애플리케이션 상태 오류는 진단 로그에 한 번 기록하며, 같은 내용을 stdout으로
재출력하지 않는다. 일반 stdout/stderr 캡처는 유지한다.

## 근거와 영향

CRS를 추측하거나 큰 파일 전체를 메모리에 읽으면 위치 오류나 메모리 초과가
발생할 수 있다. 누락된 정보를 레이어별로 격리하면 정상 파일의 표시와 원본
정보 수정이 가능하다. 원본 범위가 없는 파일은 메타데이터 수정 전까지
렌더링되지 않는다.
