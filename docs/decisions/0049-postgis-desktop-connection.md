# ADR 0049: 데스크톱 PostGIS 연결과 확장 확인

- 상태: 채택 (2026-11-01)
- 기준: `desktop-gis-codex-brief.md` 2.7, 3단계 MVP

## 결정

데스크톱 PostGIS 테이블 창에 PostgreSQL 호스트, 포트, 데이터베이스, 사용자, 암호,
SSL 모드 입력을 제공한다. 빈 양식에서는 기존 `GOGIS_POSTGIS_DSN`을 사용한다.
접속 정보는 실행 중 메모리에만 유지하고 작업공간, 설정 파일, 진단 로그에 저장하지
않는다. DB 연결 뒤 `pg_extension`을 조회해 선택한 데이터베이스의 PostGIS 확장
설치 여부와 버전을 확인한다. 확장이 없으면 테이블 목록과 로드를 중단하고 오류를
표시한다. 앱은 `CREATE EXTENSION`을 실행하지 않는다.

기존 viewport 읽기, 레코드 편집과 CLI 가져오기/내보내기 경로를 유지한다. 데스크톱
PostGIS 내보내기는 메모리에 완전히 로드된 단일 프로젝트 레이어를 선택한 테이블에
트랜잭션으로 저장한다. 대상 테이블의 데이터가 교체된다는 사실을 UI에 명시한다.
큰 읽기 전용 레이어는 일부 데이터만 저장하는 사고를 막기 위해 이 경로에서 거절한다.

## 제한과 검증

현재 PostGIS 드라이버의 쓰기 테이블 구조는 `id`, `geom`, `properties`이다.
테이블 목록은 이 구조에 맞는 공간 테이블만 표시한다.
임의의 기존 업무 스키마를 편집하는 기능은 별도 설계가 필요하다. 기존 테이블을
대상으로 내보내기 전에 스키마 호환성을 확인해야 한다. 접속 실패와 확장 부재는
쓰기 전에 보고한다. 라이브 DB 트랜잭션 검증은 `GOGIS_TEST_POSTGIS_DSN`이
있는 개발 환경에서 수행한다.
