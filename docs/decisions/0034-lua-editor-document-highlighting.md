# ADR 0034: Lua 편집기 문서 직접 강조

Lua 편집기는 입력용 `TextArea` 위에 별도 HTML 텍스트를 겹쳐 구문을 강조했다.
포커스를 받으면 강조 레이어를 숨겼고, 두 레이어의 줄 높이와 스크롤 좌표가
달라 줄 번호와 글자가 어긋났다. 긴 줄은 오른쪽에서 잘렸다.

Qt의 `QSyntaxHighlighter`를 `TextArea`가 사용하는 `QTextDocument`에 연결한다.
이로써 편집 중에도 구문 색상이 유지되고 입력과 강조가 같은 글자 배치를
사용한다. 긴 줄은 편집기 너비에 맞춰 줄바꿈하고, `Flickable`이 세로 스크롤을
담당한다. 줄 번호는 각 논리적 줄의
시작 위치를 `positionToRectangle()`으로 구해 배치하므로 줄바꿈된 행에도
번호가 정확한 시작 행에 붙는다. 화면에 보이는 번호만 생성한다.

구문 강조기는 UI 드라이버인 Qt 경계에만 두며 Lua 실행, 공용 명령 API,
스크립트 저장 형식은 변경하지 않는다. QtGui와 QtQuick은 기존 의존성이다.
