# 프로젝트 단위 DXF 내보내기

## 결정

데스크톱의 DXF 내보내기는 활성 레이어 하나가 아니라 프로젝트의 모든 레이어를
한 파일에 기록한다. CAD 레이어명은 프로젝트에서 설정한 표시 이름을 사용하고,
해당 피처의 TEXT도 같은 CAD 레이어에 둔다. 표시 이름이 없으면 내부 이름을
사용한다. 동일한 CAD 레이어명이 중복되면 조용히 병합하지 않고 오류를 표시한다.
저장 대화상자 앞의 설정 창에서 레이어 포함 여부, CAD 이름, 도형·레이블 내보내기
여부를 선택할 수 있다. 아무것도 선택하지 않거나 선택한 레이어에서 도형·레이블을
모두 끄면 오류를 표시한다. 기본값은 프로젝트의 모든 레이어와 두 항목 모두 포함이다.

## 근거와 영향

활성 레이어만 내보내면 연속지적도·지적도근점·건물과 같은 복합 작업에서 데이터가
누락된다. 내부 이름을 쓰면 CAD에서 작업의 레이어명을 식별하기 어렵다.
읽기 전용 소스는 레이어별로 다시 열고 기록하므로 모든 대용량 레이어를 동시에
메모리에 올리지 않는다. 기존 단일 레이어 exporter API와 CLI 출력은 호환성을
위해 유지한다. 실패 시 임시 파일만 제거하고 이전 출력 파일은 보존한다.

GDAL 재읽기 및 자동 테스트는 구조 검증이며 ARES Commander 실제 표시와는 별도로
Windows에서 세 레이어 이름·도형·레이블을 확인한다.
