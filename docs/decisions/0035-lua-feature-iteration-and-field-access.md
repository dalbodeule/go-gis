# ADR 0035: Lua 속성 열거와 필드 참조

GopherLua의 `pairs`/`next`는 테이블의 원시 항목만 순회한다. 읽기 전용 `feature`
프록시에는 원시 항목이 없어서 `feature.NAME`은 읽히지만 `pairs(feature)`는
빈 결과를 냈다. 레이블·필터의 `pairs(feature)`와 `next(feature)`가 보호된
속성 테이블을 순회하도록 한다. 반복자의 상태로는 프록시만 돌려주므로
스크립트가 원본 속성 테이블을 수정할 수 없다. 일반 Lua 테이블의 동작은 유지한다.

필드 삽입은 Lua 예약어를 점 표기법에서 제외한다. 그 밖에 점 표기법을 사용할
수 없는 이름은 대괄호와 Lua 문자열로 참조하고, 따옴표·역슬래시·제어 문자를
Lua 문법에 맞게 이스케이프한다. 필드의 실제 이름은 바꾸지 않는다.
