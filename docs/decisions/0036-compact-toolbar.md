# ADR 0036: 좁은 창의 작업 버튼과 대화상자 위치

최소 창 너비 960px에서 상단 `RowLayout`의 버튼들이 화면 밖으로 밀려
정보와 설정에 접근할 수 없었다.

창 너비가 1360px 미만이면 프로젝트 좌표계, 정점 편집, GoGIS 정보, 설정을
`더보기` 메뉴에서 제공한다. 파일 추가·PostGIS·작업공간 열기·속성·저장/내보내기는
상단에 남긴다. 1360px 이상에서는 기존 버튼을 표시한다. 두 화면에서 같은
대화상자와 편집 동작을 호출한다.

최소 창 너비에서 메뉴 버튼의 오른쪽 끝이 창 안에 있는지, 메뉴에서 정보·설정·
프로젝트 좌표계 대화상자를 열 수 있는지 QML 테스트로 검증한다. 한국어 960×640 offscreen
화면에서도 버튼이 잘리지 않는 것을 확인한다.

같은 화면 점검에서 여러 modal 대화상자가 창 좌상단에 붙어 열리는 것을
확인했다. 이미 중앙 배치되던 좌표계·로그 창과 일관되도록 생성, CSV,
업무 워크플로우, 공간 연산, PostGIS, 레코드 추가·삭제, 레이어 제거·속성,
Lua 편집기, 속성 테이블, 앱 설정·정보 창도 overlay 중앙에 배치한다.
960×640 offscreen 화면에서 주요 대화상자의 제목과 확인/취소 버튼이
창 안에 있는지 확인했다.

Lua 편집기는 세 편집 영역을 세로로 쌓은 구조에서 세 탭으로 바꿨다. 최소 창
높이에서 마지막 편집기를 찾으려고 대화상자 전체를 스크롤해야 했기 때문이다.
탭마다 하나의 코드 영역을 넓게 쓰고, 필드 삽입과 예제는 선택한 스크립트에
적용한다. 확인은 세 스크립트를 함께 반영하고 취소는 편집 전 값을 유지한다.
