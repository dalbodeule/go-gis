# ADR 0030: 마일스톤 D 대화형 입력 예산과 조인 정책

상태: Accepted — 2026-10-24

대화형 CSV 점 가져오기와 대장 조인은 각각 최대 10만 행, 파일 크기 16 MiB로
제한한다. 현재 프로젝트 모델은 입력과 렌더용 복사본을 메모리에 유지하므로
100만 행 벤치마크에서 파싱만 약 0.8GB를 할당했다. 상한을 초과하면 결과
레이어를 만들지 않고 파일 분할 또는 CLI 사용을 안내한다. CLI는 기존 드라이버
한도와 사용자의 실행 환경에서 처리하며 이 대화형 상한을 적용하지 않는다.

CSV 미리보기는 앞부분 1 MiB와 정상 샘플 3행, 최대 12개 검사 행으로 제한하고
셀 표시 길이도 줄인다. 잘못된 행의 전체 건수는 보존하되 상세 오류는 처음
100건만 보유한다. 필드 형식을 명시한 숫자·불리언은 잘못된 문자열을 원문으로
조용히 넘기지 않고 해당 행을 거부한다. GUI 취소는 가져오기 중 별도로 감지해
파싱을 중단하고 프로젝트에 부분 레이어를 추가하지 않는다.

대장 키가 중복되면 조인을 중단한다. 여러 피처가 같은 대장 행을 참조하는 것은
허용하며, 매칭된 피처 수와 사용되지 않은 대장 행 수를 각각 센다. GUI의
미매칭 결과는 실패가 아닌 작업 요약으로 표시한다. 속성 조회는 프로젝트 전체
복사본 대신 요청한 피처 하나를 복사해 오래된 속성값과 불필요한 보유 메모리를
피한다.

GUI에서 파생된 결과 레이어는 원본 파일 경로를 승계하지 않는다. 원본 경로를
남기면 작업공간을 다시 열 때 계산·조인 결과가 원본 데이터로 대체될 수 있다.
파생 레이어는 도형을 잠근 쓰기 가능 상태로 추가하고, 명시적으로 만든 빈
레이어만 도형 잠금을 해제해 시작한다.
새 레이어는 지도 렌더 소스와 가시성 목록에도 즉시 등록한다. 기존 지도 범위를
벗어난 결과가 추가되면 전체 소스를 공통 범위에 다시 맞춰 위치가 어긋나지 않게 한다.
