# ADR 0033: Lua 표시용 보조 함수

레이블과 표시 필터에서 숫자 천 단위 구분, 빈 값 대체, 문자열 정리, 포함 검사를
반복해서 작성해야 한다. 기존 편집기의 포함 검사 예제는 샌드박스가 비활성화한
`string.find`를 호출해 실행할 수 없었다.

피처별 레이블 평가기와 프로젝트 Lua 실행기에 동일한 순수 `gogis` 보조 함수를
등록한다: `format_number`, `coalesce`, `trim`, `contains`. 이 함수는 GIS
명령을 실행하거나 파일·UI에 접근하지 않으며 기존 공용 명령 API를 변경하지 않는다.
`contains`는 패턴 대신 리터럴 포함 검사만 제공하고, 문자열 입력은 1 MiB로
제한한다. `format_number`는 소수점 0~6자리와 쉼표 구분을 명시하며 숫자가
아닌 문자열은 `nil`로 처리한다. 편집기 예제는 이 함수들을 사용한다.
