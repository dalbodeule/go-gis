# 앱 설정

상단 도구 모음의 톱니바퀴 버튼에서 앱 기본값을 설정한다. 현재 제공하는
기본 설정은 표시 언어와 큰 Shapefile의 자동 공간 인덱스 생성 기준이다.

| 값 | 동작 |
| --- | --- |
| 시스템 기본값 (기본) | 운영체제 언어가 한국어 또는 일본어이면 해당 언어를 사용하고, 그 외에는 영어를 사용한다. |
| 한국어 / English / 日本語 | 선택 즉시 화면에 적용하고 다음 실행에도 유지한다. |
| Shapefile 자동 공간 인덱스 기준 (기본 10,000) | 해당 피처 수 이상의 SHP를 열 때 OS 임시 캐시에 QIX를 만든다. 값 `0`은 자동 생성을 끈다. 원본 폴더는 수정하지 않는다. |

설정은 Qt의 플랫폼별 사용자 설정 저장소에 기록한다. 앱 식별자는 실행 파일명과
무관하게 `GoGIS`로 고정한다. `--lang ko`, `--lang en`, `--lang ja` 실행 인자는
저장된 언어보다 우선하며 설정값을 덮어쓰지 않는다. `--lang`을 지정하지 않으면
저장된 선택을 사용하고, 저장된 선택이 시스템 기본값이면 OS locale로 결정한다.

**기본값으로 초기화**는 표시 언어를 시스템 기본값으로 돌리고 인덱스 기준을
10,000으로 되돌린다. 앞으로 시작 시
동작과 기본 좌표계처럼 데이터나 작업 환경에 따라 달라질 수 있는 값은 임의로
고정하지 않는다. 인덱스 기준 변경은 다음 앱 실행부터 적용된다. `--spatial-index-threshold`,
`--spatial-index-location` 인자와 `GOGIS_SHAPEFILE_INDEX_THRESHOLD`,
`GOGIS_SHAPEFILE_INDEX_LOCATION` 환경변수는 저장 설정보다 우선한다.
